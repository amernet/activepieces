# piece-salesbay

Activepieces piece for **Salesbay** (Amernet AI Growth Engine).

Actions:
- **Create Contact** — add a contact to a Lead Finder list
- **Enroll Segment in Drip Workflow** — push a Smart Segment audience into an active drip workflow (deduplicated)
- **Find Smart Segments** — list the workspace's reusable audiences
- **Custom API Call** — any other `https://saas.salesbay.ai/api/v1` endpoint

Auth: Salesbay API key (Settings → API Keys), sent as a Bearer token.
